- Game name - "Frost runner"

- The project is an endless runner game where the player controls a ship and trys to score as many points as possible without hitting any of the obstacles.
There are boost pads and shields to help the player survive and score more points.

- Simply start the exe and hit play.
- CONTROLS: A - move left, D - move right, ESC - menu
- Try to dodge all the obstacles and score as many points as possible.

The game is a collection of scenes and scripts in godot. The scripts are in GDScript/Python. The player starts on a flat surface which constantly spawns every few seconds and avoids obstacles spawned every 8 or so seconds depending. The player and obstacles have colliders that cause the player death() function to run, playing an explosion, particles, and death screen.
